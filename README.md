🚀 RBAC System (Java Web App)

A simple Role-Based Access Control (RBAC) system built using Java, JSP, Servlets, and JDBC.
This project demonstrates user authentication and role-based authorization.

📌 Features
 User Registration & Login
 Role-Based Access (Admin / User)
 Session Management
 Secure Authentication
 Database Integration using JDBC

🛠️ Tech Stack
  Java
  JSP & Servlets
  JDBC
  MySQL
  Apache Tomcat

  ⚙️ Setup Instructions
1)Clone the repo
{git clone https://github.com/anurajkhandagale/rbac-system   }
2)Open in IntelliJ / Eclipse
3)Configure database (MySQL)
4)Add server (Apache Tomcat)
5)Run project
